# Praveen-kumar-III-CSE-
# 📘 Spring Boot Assignments

## 📌 Overview
This repository contains a set of beginner-friendly assignments to understand the core concepts of Spring Boot. It covers application setup, controllers, configuration, Actuator, POJO, Lombok, DAO, and RESTful HTTP methods.

---

## ✅ Assignment 1: Run First Spring Boot Application

### 🎯 Objective
To create and run a basic Spring Boot application in a web browser.

### 📋 Description
- Create a Spring Boot project
- Run the application
- Access it through a browser

### 📌 Outcome
- Understanding how to start and run a Spring Boot application

---

## ✅ Assignment 2: Controller, Port Change & Actuator

### 🎯 Objective
To implement a controller, change the server port, and explore Actuator endpoints.

### 📋 Description
- Create a controller to handle requests
- Change the default server port
- Enable and check Actuator endpoints (health, beans)

### 📌 Outcome
- Understanding controllers and request handling  
- Knowledge of configuration changes  
- Basic monitoring using Actuator  

---

## ✅ Assignment 3: POJO, Lombok & DAO

### 🎯 Objective
To create a POJO class using Lombok and implement a DAO layer.

### 📋 Description
- Create a POJO class  
- Use Lombok to reduce boilerplate code  
- Implement DAO (Data Access Object)  
- Retrieve and display data  

### 📌 Outcome
- Understanding of POJO and Lombok  
- Basic knowledge of DAO pattern  

---

## ✅ Assignment 4: HTTP Methods

### 🎯 Objective
To understand and implement RESTful HTTP methods.

### 📋 Description
- Learn HTTP methods: GET, POST, PUT, DELETE  
- Perform CRUD operations  
- Test APIs using browser or tools  

### 📌 Outcome
- Understanding REST APIs  
- Ability to perform CRUD operations  

---

## 📊 Learning Outcomes

By completing these assignments, you will:
- Understand Spring Boot basics  
- Work with controllers and configurations  
- Use Actuator for monitoring  
- Implement POJO, Lombok, and DAO  
- Build RESTful APIs  

---

## 🚀 Conclusion
These assignments provide a strong foundation in Spring Boot and help in developing backend applications efficiently.
